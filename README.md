# Minecraft Dingo Character Skin

DingoDash is a Minecraft character skin texture featuring a sandy golden-orange dingo with pointed ears, warm amber eyes, and a party-adventurer outfit. The 64×64 SVG texture combines teal and red clothing, a dark leather vest, plaid accents, rolled jeans, and boots.

## Install

1. Download `assets/textures/dingo_party_adventurer.svg` from the project.
2. Convert the SVG texture to a 64×64 PNG using an SVG editor or converter that preserves transparency and crisp pixel edges.
3. Open the Minecraft Launcher and select the Java Edition profile you want to customize.
4. Open the Skins tab, choose New Skin, and upload the converted PNG.
5. Save and select the skin.

## Use

1. Launch Minecraft Java Edition with the profile using the new skin.
2. View the dingo character in-game.
3. If the skin appears incorrectly, check that the exported image is 64×64 pixels with transparency preserved.
